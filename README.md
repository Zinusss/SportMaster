# ⚡ SportMaster AI — Персональний AI-трекер харчування та тіла

Сучасний, швидкий та кросплатформений веб-додаток (PWA) для детального відстеження харчування, розрахунку КБЖВ, аналізу страв через штучний інтелект **Google Gemini**, контролю активності та інтерактивного коучингу.

Розроблено спеціально для зручного використання на **iPhone (iOS)** як нативний додаток на домашньому екрані, а також на комп'ютері чи Android.

---

## ✨ Основні можливості

### 1. Розрахунок персональних норм (Онбординг)
- При першому вході вказуються стать, вік, зріст, поточна вага, бажана вага, рівень фізичного навантаження та мета (схуднення, підтримка, набір маси).
- Автоматичний розрахунок за медичною формулою **Mifflin-St Jeor**:
  - **BMR** (базальний метаболізм)
  - **TDEE** (добова витрата енергії з урахуванням активності)
  - Цільові **калорії** з урахуванням дефіциту (-10..-20%) чи профіциту (+10..+15%)
  - Баланс **БЖВ** (Білки, Жири, Вуглеводи) у грамах та норма води.

### 2. Три способи запису їжі (Сніданок, Обід, Вечеря, Перекус)
1. **Ручний ввід (КБЖВ)**: швидке введення грамів білків, жирів, вуглеводів та калорій.
2. **Розумний текст (Gemini AI)**: напишіть звичайною мовою страву та вагу (наприклад: *"Вівсянка 60г з бананом і медом 15г"* або *"Борщ з м'ясом 350г і ложкою сметани"*). ШІ сам розрахує точні калорії та макроси!
3. **Фото страви (Gemini Vision AI)**: сфотографуйте їжу на камеру або завантажте з галереї. Gemini розпізнає страву на тарілці, оцінить розмір порції та порахує КБЖВ!
*Перед збереженням будь-яке число можна відкоригувати.*

### 3. Gemini Sport Coach (Вбудований ШІ-чат)
- Персональний нутриціолог та фітнес-тренер прямо в додатку.
- **Повна контекстна обізнаність**: ШІ бачить ваші поточні параметри, що ви з'їли за сьогодні, скільки калорій і білка залишилось, і відповідає з урахуванням цього!
- Швидкі підказки: *"Що з'їсти на вечерю на 400 ккал?"*, *"Оціни мій раціон за сьогодні"*, *"Як закрити білок?"*.

### 4. Крокомір та спалені калорії
- Живий підрахунок кроків у реальному часі через **акселерометр смартфона** (`DeviceMotionEvent`).
- Швидке додавання (+500, +1000 кроків) або введення точного числа з Apple Health / Apple Watch.
- Автоматичний розрахунок спалених калорій під вашу вагу та коригування денного балансу!

### 5. Дизайн Apple iOS
- Темна тема в стилістиці Apple Fitness & Health.
- Кільця та шкали активності, плавні анімації, святкове конфеті при досягненні цілі.
- Повна підтримка жестів та безпечних зон iPhone (safe-area-inset).

## 🔑 Підключення Google акаунту та Gemini AI

В додатку запити до ШІ здійснюються через офіційний безкоштовний **Google Gemini API**:
1. Перейдіть у **[Google AI Studio (aistudio.google.com)](https://aistudio.google.com/app/apikey)** зі свого Google акаунту.
2. Натисніть **«Create API key»** (це 100% безкоштовно та займає 10 секунд).
3. Скопіюйте створений ключ (починається з `AIzaSy...`) та вставте його у додатку (при реєстрації або у вкладці **«Профіль»**).
4. Натисніть **«Тест Gemini ⚡»** для перевірки з'єднання. Ключ безпечно зберігається виключно у браузері вашого телефону (`localStorage`).

## 🚀 Як опублікувати додаток на безкоштовному хостингу GitHub Pages

У репозиторії вже налаштовано автоматичний GitHub Actions деплой (`.github/workflows/deploy.yml`).

### Покрокова інструкція:
1. Створіть новий репозиторій на [GitHub](https://github.com/new) (наприклад, `SportMaster`).
2. Запушіть код у ваш репозиторій:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of SportMaster AI"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_НІКНЕЙМ>/<ВАШ_РЕПОЗИТОРІЙ>.git
   git push -u origin main
   ```
3. На GitHub відкрийте сторінку репозиторію -> **Settings** -> розділ **Pages** (зліва в меню).
4. У пункті **Build and deployment -> Source** оберіть:
   👉 **GitHub Actions**
5. Готово! За 1-2 хвилини у вкладці **Actions** завершиться автоматична збірка, і ви отримаєте безкоштовне посилання:
   `https://<ваш-нікнейм>.github.io/<ваш-репозиторій>/`

## 📱 Як додати на екран iPhone як нативний додаток

1. Відкрийте посилання вашого сайту в браузері **Safari** на iPhone.
2. Натисніть іконку **«Поділитися»** (квадрат зі стрілкою вгору в нижньому меню).
3. Прокрутіть трохи вниз і виберіть **«На початковий екран»** (Add to Home Screen).
4. Натисніть **«Додати»** у верхньому правому кутку.
5. На робочому столі з'явиться фірмова іконка **SportMaster**. Додаток відкриватиметься на повний екран без рамок і вкладок браузера!
